## 💻 Coding Problems

I have worked on the following 8 TypeScript problems:

### Problem 01: multiplyValue()
- Function with an optional parameter.
- Used default parameter values.
- Performed multiplication based on the given input.

### Problem 02: processInput()
- Used Union Types (`string | number | boolean`).
- Applied Type Narrowing using `typeof`.
- Used `trim()` and `toLowerCase()`.
- Handled string, number, and boolean values.

### Problem 03: formatCoordinate()
- Used Tuple Types.
- Applied the `readonly` modifier.
- Used array destructuring.
- Formatted location information using template literals.

### Problem 04: concatenateArrays()
- Created a Generic Function using `<T>`.
- Used Rest Parameters.
- Combined multiple arrays into one array.
- Used the `flat()` method.

### Problem 05: getPopularCourses()
- Created a `Course` interface.
- Used an array of objects.
- Applied the `filter()` method.
- Used logical and comparison operators.

### Problem 06: pluckValues()
- Used Generic Types.
- Applied the `keyof` operator.
- Used Generic Constraints (`extends`).
- Applied Indexed Access Types (`T[K]`).
- Extracted specific property values using `map()`.

### Problem 07: Employee & Manager
- Created Employee and Manager classes.
- Used Constructors.
- Applied `private` and `protected` access modifiers.
- Implemented Inheritance using `extends`.
- Used `super()` and `this` keywords.

### Problem 08: validateAgeAsync()
- Created an Async Function.
- Used `Promise<string>`.
- Applied `setTimeout()`.
- Handled Promise resolution and rejection.
- Used Error Handling with `new Error()`.
